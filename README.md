Banking & Transaction Manager

A simple console-based banking system developed using Python.

Features

- Create Savings or Current accounts
- Login using Customer ID and PIN
- Check account balance
- Deposit and withdraw money
- Transfer money between accounts
- Calculate monthly interest for Savings accounts
- View account transaction history
- Generate unique Transaction IDs
- Display bank dashboard
- Input validation and account rules

Account Rules

Savings Account

- Minimum initial deposit: $500
- Minimum balance: $500
- Monthly interest rate: 5% annually / 12

Current Account

- Minimum balance: $0

Main Functions

- "create_account()"
- "find_account()"
- "deposit_money()"
- "withdraw_money()"
- "transfer_money()"
- "calculate_interest()"
- "account_statement()"
- "bank_dashboard()"

The project also includes functions for transaction management, user menus, and the main program flow.

Technologies

- Python
- Dictionaries & Lists
- Functions
- Loops & Conditions
- Input Validation

No external libraries, databases, APIs, GUI, or classes are used.

How to Run

1. Install Python.
2. Open the project in a Python editor such as VS Code.
3. Run "banking_system.py".
4. Follow the instructions in the console.
